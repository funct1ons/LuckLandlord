## 1. 冻结记录：当时核对的四项缺口

以下第1–3节完整保留冻结时及第0/1批后的记录，所有「未改」「部分」「没有」仅描述当时，不是现行缺口；最新状态以本文件上方总表为准。

### 1.1 游戏没有给玩家介绍故事背景

**冻结记录状态：已改（第 0 批）**

**缺口：** 打开游戏后，玩家看不到雾港、负债工坊、回收机这些世界设定，只有短规则摘要。

**冻结当时实况：**

- 无存档时，`js/gdd1UI/main.js` 的 `showStart()` 在决策区写入身份、10 期终点、随机上盘、现金 / 待入账说明（文案在 `js/gdd1UI/copy.js` 的 `start.*`）。
- 这段是玩法摘要，没有港口氛围、接手原因、工坊工作线或可跳过的开场。
- 已有存档时直接 `load` 恢复对局，开场文字不出现。
- 局内没有故事节拍；卡牌说明走规则合同。
- [GAME_IDENTITY.md](../GAME_IDENTITY.md) 写明当时不实施游戏内教程。

**第0/1批后实况：** 欢迎门展示 `start.story`（雾港潮湿、接手负债工坊）、`start.tagline`、identity / goal / intro，以及折叠的现金入账说明。有存档刷新仍自动恢复，不经过欢迎；玩家可用顶栏「开场」、`?menu=1` 或 `#menu` 再看故事。局内仍无故事节拍。

**目标对照：** 分册 §1、§5 首屏；GDD §1 成功体验「救活工坊，并且看得懂机器为什么赚钱」。

### 1.2 美术太素，缺少支撑世界的图像

**冻结记录状态：未改**

**缺口：** 有工业配色和线框图标，缺少能撑起工坊的画面。

**该版本实况：**

| 已有 | 缺少 |
|---|---|
| 64 生产牌 + 32 本局升级的本地描边 SVG（`js/gdd1UI/icons.js`，32×32，路线共用外框） | 绘图式卡面、物件立绘、角色、港口 / 工坊场景 |
| `css/gdd1.css` 深青、暖铜、纸色令牌 + SVG 噪声底 | 盘面珐琅机身、铆钉装饰、独立背景图 |
| Web Audio 振荡器短音效（`js/gdd1UI/audio.js`） | 背景音乐、环境层、音频文件 |
| 完全离线：不引用网络字体、CDN、位图 | 打包进仓库的插画（当时也没有） |

图标能区分八条路线，画不出「凝雾软囊」「港湾拍长」这些物件本身。道具图标几乎都是同一块铜牌加内部记号。

第 0 批在欢迎页加了一张本地 inline 机身 SVG（5×4 格、铜管、铆钉、雾），不算卡面 / 场景美术，1.2 仍未改。

**约束：** 该版本工程要求完全离线。补图须进仓库（原创 SVG / 本地画），不能运行时拉公开网址。

**目标对照：** [VISUAL_SPEC.md](../VISUAL_SPEC.md) §1 主题、§4 图标；GDD §10.1 暖铜回收机。

### 1.3 没有单独的欢迎界面

**冻结记录状态：已改（第 0 批）**

**缺口：** 没有独立主菜单 / 欢迎屏。开场是把游戏壳子空着，把说明塞进决策区。

**冻结当时实况：**

- `gdd1.html` 一打开就是对局顶栏：Seed、新精简 / 新完整、继续、存档、导出、导入、「导出错误」、自动保存、音效、演出速度。
- `showStart()` 藏盘面和账本，在 `#decision` 放标题、四段说明、两个开始按钮。
- 没有全屏标题构图，没有「图鉴 / 设置 / 退出」，继续入口仍在开发顶栏。

**第0/1批后实况：** `#welcome` 全屏工坊门；`body.welcome-open` 隐藏 `header` / `main`（DOM 保留，测试仍可点 `#new`）。门上有开始完整 / 精简、按存档启用的继续、离线小字。无存档打开欢迎；有存档自动恢复。欢迎上仍无「图鉴 / 设置 / 退出」（图鉴见 1.4，设置见 P-18）。

**目标对照：** VISUAL_SPEC §6 主菜单（标题、副标题「组合赚钱，按期付账，保住工坊」、新局、继续、图鉴、设置、离线与版本小字）。

### 1.4 没有图鉴供游玩中查阅

**冻结记录状态：未改**

**缺口：** 玩家不能浏览全部生产牌、本局升级、事件；只能看本局牌库里已经有的实例。

**该版本实况：**

- 右侧 `#pool` 是当局生产牌库列表（UID、基础值、永久成长、移除）。
- 没有按路线 / 稀有度 / 已发现筛选的全量图鉴。
- 没有发现记录、未发现轮廓、「尚未记录」。
- 盘面格子只有原生 `title` 气泡（含 UID），没有可钉住的详情层。
- README 已知限制已写：没有正式菜单 / 教程 / 图鉴 / 失败诊断面板。

**目标对照：** VISUAL_SPEC §6 图鉴；GDD §3.1、§10.3（发现只影响展示，不改候选概率）。
