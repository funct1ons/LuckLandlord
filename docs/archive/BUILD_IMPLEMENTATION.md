# M3–M5 实现交付记录

状态：待主对话审核。M0–M2 核心复测依据 `docs/CORE_RETEST.md`；本次实现扩展内容版本仍使用 rules 0.2，存档结构新增统计字段并拒绝旧结构，建议正式合并前将 VERSION 提升为 2。

## 已实现

- 正式内容数据：64 个正式符号（另保留 20 个原型符号供回归 fixture），32 个唯一持续道具，8 个事件定义。
- 8 条路线 ID 与标签体系：培育、回收、共振、蒸馏、货运、蓄能、映印、契约。
- 候选池只从正式符号生成，并排除 `spent_gasket` / `arrears_slip` 污染产物；候选持久化仍沿用 revision 校验。
- 阶段奖励改为唯一道具，不再显示 M2 的 repair/calibrate/cash 占位奖励。
- 选择、跳过、刷新、删除、阶段付款和统计字段（选择计数、跳过、刷新、事件计数）接入命令状态。
- 道具效果总线第一批已接入结算：露班轮历、分温围裙、清栈细网、夜单夹、薄账分页条等按本轮存活盘面实际改变收益。
- UI 道具名称从数据读取，状态文案标识 M3–M5 构建版；原型符号仍可用于 debug/fixed-board 回归。
- M5 Bot：Random / Value / Synergy / Greedy 均走真实 `spin → choose/skip → reward` 命令，Bot RNG 与游戏 RNG 分离，训练/留出 seed 前缀分离。

## M5 统计

`tests/m5-report.json` 为四 Bot 各 125 局训练 + 125 局留出，共 1,000 局；每局均通过真实命令，异常数组为空。由于当前解析器在 8,000 局目标下超过 120 秒，本次选择 1,000 局可复现门槛并保留耗时限制为遗留问题。结果显示四 Bot Normal 胜率均为 100%，说明当前经济仍明显过易，不能视为平衡通过；Value 仍未解决“过易”问题。

未进行人工完整试玩、Chrome/Edge 三分辨率人工操作，因此这些项目保持待测，没有冒称通过。
