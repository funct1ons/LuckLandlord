# M5 平衡报告（待审核）

## 样本与方法

- 规则版本：0.2；正式符号 64、持续道具 32、事件定义 8。
- Bot：Random、Value、Synergy、Greedy。
- 每个 Bot：125 个训练 seed + 125 个留出 seed，共 250 局；总计 1,000 局。
- seed 通过 `TRAIN-<bot>-N` / `HOLD-<bot>-N` 分离；Bot 选择使用独立 RNG，不污染游戏 RNG。
- 所有局均调用真实命令：Spin、符号选择/跳过、刷新策略入口、阶段道具选择；异常不筛除，直接记录在 `errors`。

## 结果

完整机器可读结果见 [`tests/m5-report.json`](../tests/m5-report.json)。当前四类 Bot 在训练和留出集均达到 100% 胜率，异常为 0。现金分位、平均阶段、选择数和跳过数均已记录。该结果暴露 Normal 经济明显过易，尤其 Value Bot 仍然不是有意义的难度基线；不得将此报告解释为平衡通过。

## 结论与下一步

当前应先收紧 Normal 现金曲线和持续道具投放，再运行新的训练/留出集。不能通过筛掉失败 seed、预设胜率或只报告成功局改善结论。四 Bot 行为差异已经存在，但道具/事件机制尚未完整接入，因此本报告只作为 M5 基线。

人工试玩、Chrome/Edge 实机与三分辨率检查本轮未执行，保持待测。
