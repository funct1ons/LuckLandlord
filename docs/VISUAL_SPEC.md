# 《雾港回收工坊》现行视觉规格

> **已批准方向 A：雾港夜班 · 手绘工业奇幻工作台。** 方向依据见 [视觉提案](archive/VISUAL_DIRECTION_PROPOSAL.md)。本轮使用原创程序化2D插画实现绘画式体积，不冒称真人手绘。
>
> 从属于 [GAME_DESIGN_V1.md](GAME_DESIGN_V1.md) 与 [GAME_IDENTITY.md](GAME_IDENTITY.md)。仅定义表现层，不改变故事、规则、RNG、付款表、内容ID或存档schema。运行时完全离线。

## 1. 空间与气质

窗外冷雾、码头与远灯；窗内暖工作灯、被照料的旧铜/珐琅机器、玻璃、植物、账簿与木柜。气氛安静、神秘，有经营压力，不是恐怖、霓虹终端或全屏黄纸。

主次为：**机器与操作 → 账单和现金 → 构筑柜 → 环境**。装饰不能伪造能源、设备状态或可自由摆牌的暗示。环境静止，不额外增加循环动画；现有音乐和短促操作音保留。

## 2. 色彩与材质

现行入口 [css/gdd1.css](../css/gdd1.css)，单一组件样式与断点，不以重复覆盖维护多套视觉。主要令牌：

| 职责 | 现行颜色 |
| --- | --- |
| 房间深部 | `#142126`，`--ink-950: #101b1d` |
| 深色漆面 | `--ink-900: #172628`，`--panel-700: #2b3d3a` |
| 纸张与主要文字 | `--paper: #eee3c9` |
| 旧铜/暖光 | `--copper: #a66f48`，`--amber: #e3ba79` |
| 玻璃与植物 | `--mint: #9dbfaf` |
| 危险与焦点 | `--danger: #eb9784`，`--focus: #ffe3a0` |

铜靠高光、接缝与暗面；玻璃靠厚边、液面、透明叠层；纸面靠温和明度变化；木柜靠结构和顺向纹理。规则文字背后不叠噪声。路线色只作辅助，有名字、形状与中文标签，不是唯一语义。

正文与控件用本地系统字体栈；标题、金额和纸面名称用本地宋体/衬线回退，金额保持等宽数字。没有下载字体。盘面/列表的小字是摘要，候选与详情始终保留完整规则及代价。

## 3. 对局构图

```text
工坊招牌          现金 / 待入账                  开场 · 图鉴 · 帮助 · 设置

本期账单夹             旧铜回收机                      构筑木柜
应付 / 现金缺口    ┌───────────────────┐           生产牌库 / 本局升级
剩余运行           │ ○   ○   ○   ○   ○ │           标签切换与实例查阅
                   │ ○   ○   ○   ○   ○ │
刷新券 / 删除券    │ ○   ○   ○   ○   ○ │
                   │ ○   ○   ○   ○   ○ │
                   └───────────────────┘
                       实体运行键
                       本轮账本与折叠日志
```

- 默认三栏：左176px账单夹，中央自适应机器，右260px构筑柜；内容最大宽度1560px。大桌面侧栏为195/290px。
- 顶栏只强调现金与待入账。应付、余轮、现金缺口集中在真实账单；缺口按当前已入账现金计算，不暗示待入账已可支付。
- 刷新券/删除券是左侧票据，不画虚构表盘。Seed、导出、导入、测试按钮仍在「存档与工具」内。
- 机器外框具有厚度、圆角、铆钉与铜连接；二十槽始终为**5列×4行**，不能拖动摆牌。
- 空槽有凹陷而无格号；普通牌用温和纸骨色衬底，物件主图、名称与收益最突出。离场有「已回收」盖章，不只是换色。
- 运行键嵌在机器控制台中；账本在机器下方。右侧标签可点击或用方向键切换，列表内部滚动，不能挤掉运行入口。

## 4. 场景与物件资产

### 场景

[assets/art/scenes](../assets/art/scenes/) 保留1920×1080欢迎/房间SVG源稿与本地PNG烘焙版本；机身装饰为1000×700轻量SVG。运行时欢迎与房间读取PNG，减少全屏噪声滤镜的绘制成本。

`scene.js` 的 `welcome()`、`room()`、`machine()` 返回装饰图片HTML，URL相对脚本位置解析；场景不接收游戏状态，`pointer-events:none`，没有文字或操作烘焙在画中。欢迎以冷港窗—机器—工作台建立远中近景，左侧留给真实HTML操作。

### 96件物件插画

`icons.js` 内联输出128单位网格的原创彩色SVG；静态源/图集在 [assets/art/objects](../assets/art/objects/)。64生产牌、32升级均具有独立几何，不以统一徽章换色充数。固定左上暖光、右下暗面、接触阴影；帮手使用有工具和职业服装的胸像。

| 入口 | 显示尺度 |
| --- | --- |
| 盘面 | 约40–76px，依高度与断点变化 |
| 牌库/升级 | 约29–42px |
| 图鉴 | 约62–72px |
| 候选 | 桌面128px，窄窗88px |
| 详情 | 128–144px |

大小图共用重新制作的128单位插画，不放大旧32单位线稿。40px依主轮廓与材料色识别，细缝线不要求保留；120px图集用于检查大图材质。每次内联渲染生成独立渐变ID，避免同页多实例串色。UI接口及内容ID保持兼容。

八条工作线保留植物/软囊、钳与废料、音叉/鸣片、厚玻璃/晶体、货笼、压力阀、错位薄片、票据核章的形态差异。详见 [素材记录](ASSET_LICENSES.md)，不附带新的法律许可。

## 5. 候选与详情

候选是工坊物件档案：**插画 → 名称/标签 → 用途 → 完整效果 → 明确操作**。桌面三张并排，窄窗纵向，卡内不隐藏条件、污染、代价和例外。

- 按钮写「选择并入账」「跳过并入账」；新牌从未来运行起生效，不补本轮或当期缺口。
- 顶部可查看盘面和整理牌库；保底刷新、移除与覆盖新局使用自定义确认。
- `#decision` 和真实候选按钮移入非可绕过modal，教程在需要时随真实操作移动，保留测试DOM。
- 盘面、实例、候选、升级可打开抽屉；大插画配完整规则、成长和计数。技术编号只留在详情。
- 宽屏悬停约250ms显示轻量预览；键盘Enter或点击打开可钉住详情，窄窗不依赖hover。

## 6. 欢迎、菜单、图鉴、设置与结局

**欢迎：** 每次打开/刷新都先显示。第一层为身份与目标、完整模式主要动作、教程选择、图鉴/设置/帮助；精简试验、完整故事与入账说明折叠。已有存档时「继续」优先，恢复不重启教程。模式分别存档，不提供浏览器退出按钮。

**图鉴：** 完整104项（64/32/8），局内按合法profile显示；种类、路线、稀有度、发现筛选。未知条目以低透明度灰色轮廓与「尚未记录」遮蔽名字/效果，发现不改变候选。没有首次发现期或路线关系图。

**设置：** 音量、速度、减少动态、屏震、对比增强、自动保存与快捷键说明，沿用工坊档案材质。偏好、教程、发现、遥测仅独立UI键；不进游戏JSON。

**结局：** 完整/精简标题明确区分，应付、付款后余额或失败现金/缺口、Seed、最终牌库/升级、近五轮均值、MVP、主副路线、关键牌上盘记录。只使用已记录轮次；路线按最终数量，MVP是归因收益，不宣称反事实贡献或整局总收益。支持再来一局、复制Seed、查看构筑、返回开场，复制失败也有可读提示。

## 7. 演出与状态隔离

先提交结果和存档，再播放滚轮/收益/入账/付款；速度与跳过不改变游戏状态。新局、菜单、导入使旧演出失效，不能由迟到Promise重开过期弹层。

普通滚轮约1–2秒，快速缩短等待，即时/减少动态直接显示最终结果；入账/付款反馈普通约620ms、快速180ms。表现层临时节点和Web Animations可清理；长日志保留完整账本，不逐条长时间播放。后台停止演出，重复运行受保护。

## 8. 声音

保留现有原创合成声音：机械启动、停列、铜片收益、路线触发、消耗、倍率、付款及胜败。32秒背景循环为棕噪雾层、C/G低频与稀疏五声音阶铜击，没有外部采样。

默认总70%、音效65%、音乐20%。首次可信用户手势初始化；设置可静音并保留已保存的0。切后台暂停、返回按设置恢复；AudioContext不可用仍可完整游玩。音频随机源与游戏RNG分离。自动生命周期测试不等于真实设备响度、疲劳或音色验收。

## 9. 键鼠与无障碍

- Space运行/跳过演出；1–3选择；S跳过候选；R刷新；Esc关闭最上层可关闭查阅层，不绕过必要候选。
- 按钮聚焦时保留Space原生语义；输入框、教程、确认、其他查阅层阻止游戏误操作；长按与组合键不连发。
- 弹层Tab循环，关闭恢复触发点；构筑柜标签支持方向/Home/End。确认默认聚焦取消，Enter/Space只激活当前按钮，长按不批准；嵌套确认隔离底层并恢复焦点。
- 清晰焦点外框、禁用态、完整中文标签。对比增强是可选辅助，不宣称已完成所有WCAG/色盲审核。
- 系统和设置减少动态取更严格值；禁用滚轮、屏震与连线等，规则反馈仍可读。

## 10. 分辨率

| 视口 | 行为 |
| --- | --- |
| 1366×768 | 三栏；盘面、账单、现金与运行在视口内；长牌库内部滚动 |
| 1920×1080 | 三栏和物件放大，保留背景空间；不铺满整屏 |
| 2560×1440 | 同一1560px内容上限，字号不缩小；两侧为环境 |
| 390×844 | 账单横排、机器五列、构筑移至下方；候选纵向，必要时弹层内部滚动 |

900/600px主要断点；窄窗兜底仍是真实二十槽，不能变为三列。禁止横向溢出。所有关键桌面操作必须无需下滚，窄窗长详情允许纵向滚动。
