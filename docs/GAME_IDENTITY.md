## 1. 定位与故事的唯一详细规范

你接手了一间负债的雾港回收工坊。
工坊的回收机随机运转，材料、设备与帮手互相配合，带来现金收入。
你要在每期截止前付清本期账单：成功付清10期，保住工坊；任一期到期、本轮收益入账后现金仍不足本期应付，本局经营失败。
核心体验是看懂机器如何赚钱，用选择逐步救活工坊，而不是手动摆位或按停滚轮。

### 工业奇幻边界

- 雾港是潮湿、铜锈、机器轰鸣的港口；暖铜与深青的既有视觉方向保留。
- 雾气是可处理的雾料，不是额外环境数值。
- 植物是工坊培育的生产材料；成熟表现来自已有出现计数与转换。
- 声音与共鸣是机器部件的协作风味；不新增音高操作或节奏小游戏。
- 晶体是精炼与异相加工材料；其收益和转换只按既有效果。
- 契据、回执、邮戳是工坊账务风味；既有条件收益与借支仍按规则运行。
- 装置与帮手可同样表示为生产牌，不新增雇佣人数、工资或客户系统。
- 机器产出及独立奖励计为纯虚拟现金，再用现金支付账单；不模拟订单结算链。

### 不新增的系统

没有能源计量、城市供能主目标、客户、采购、商店、利息或动态债务余额。
没有真实日历、自由摆位、手动出牌、手牌、战斗、现实赌博、真钱或局外成长。
“负债”说明接手原因，“账单”映射已有阶段付款，不是新债务模拟器。
已有借支或事件可能提高本期应付，必须保留真实义务，不包装成免费赠款。
终局“保住工坊”不意味着新增资产估值、还清动态总债务或无限经营模式。

## 2. 玩家先明白的概念

1. **身份与终点**：你经营工坊；赚现金、付本期账单，付清10期保住工坊。
2. **自动上盘**：每次运行从生产牌库无放回抽取至多20张，随机排入5×4盘面。
3. **构筑而非摆牌**：选择、跳过、移除、刷新和本局升级影响未来运行，不让你手动排盘。
4. **先定收益后入账**：盘面结算产生待入账；选一张或跳过后，该轮已定收益才入现金。
5. **到期付款**：最后一轮仍要选择或跳过，然后入账并付款；新牌不补本轮收益或付款缺口。
6. **看目标和代价**：标签是效果筛选条件；消耗会失去目标牌，不只是亮起组合线。

### 牌库、概率与重复牌

生产牌是既有symbol实例的表示，不意味着玩家拥有可手动打出的手牌。
同名多张各有独立身份、成长值与计数；“不同种类”按定义ID去重，不按张数。
牌库不超过20张时全都上盘，新增正收益牌通常填空，不必然稀释出现率。
它仍会改变空格条件与邻接关系；“全上盘”不等于“必定相邻”。
牌库超过20张才需要讨论抽中概率；有权重时不把20/N当精确概率。
少数明确的保留、权重效果可影响出现机会或下一轮位置，但不提供自由摆位。
移除可能提高核心同盘机会，但不保证相邻、盈利或通关。
不强迫玩家只走一条路线，也不建议无条件删除所有重复牌。

### 生命周期与成长

消耗使目标离开生产牌库，并按规则产生成功消耗/销毁事件；被消耗目标本轮普通产出为0，明确规定的独立奖励另计。
销毁与消耗的监听范围不同；主动移除不是消费或销毁奖励的触发方式。
转换保留实例身份与通用永久值，换成另一种牌，并按规则清理类型计数等状态。
永久成长跟随单张实例，仅在本局有效，不是账号或局外永久升级。
年龄、拍点等按该实例实际上盘次数推进，不按全局轮数自动前进。
只有明确效果才蓄压；带“蓄压类”标签不代表必然有蓄压计数器。

## 3. 术语对照：玩家界面统一用新词

旧词允许存在于技术合同、历史证据及未同步文件；迁移时逐处按语义对照，不做全局替换。

| 内部技术名 | 旧玩家词 | 新玩家词 | 实际含义 | 误解边界 |
|---|---|---|---|---|
| cash / currency | 凭证、金币 | 现金 | 当前已入账的纯虚拟金额 | 无真钱、兑换或第二货币 |
| payment / quota | 配额、供能配额、租金 | 本期账单；金额称本期应付 | 到期扣除的实际阶段付款 | 不计能源、不显示虚构总债务 |
| basePayment / modifiers | 基础配额、增额 | 基础账单、事件增额、借支增额 | 实际付款的可解释组成 | 不隐去既有额外义务 |
| symbol / type | 符号、符号类型 | 生产牌／生产牌种类 | 同一种定义可有多张牌 | 不是手牌或出牌动作 |
| instance / UID | 实例、实例编号 | 某一张生产牌 | 各张有独立身份、永久值与计数；编号仅技术详情使用 | 同名不等于同一张，成长不共享 |
| pool | 池、符号池 | 生产牌库 | 未来抽取实例的集合 | 不等于本轮盘面 |
| board / draw | 板、抽盘 | 盘面／上盘 | 本轮被抽取并随机排列 | 不可自由摆位 |
| Spin / spin | Spin、转动 | 运行／一轮 | 一次抽取与结算流程 | 演出不是反应小游戏 |
| stage / stageId | 阶段 | 期 | 到下一次付款的窗口 | 没有真实日历 |
| pendingSettlement | 待结算、未结算 | 待入账 | 本轮已经确定、选择后入账的净收益 | 新牌不重新计算该轮 |
| item / persistent item | 道具、持续道具 | 本局升级 | 不上盘、改变本局规则的奖励 | 只本局，不是可出牌实例 |
| rerollTokens / reroll | 重抽、刷新 | 刷新券／刷新 | 换整组候选 | 不换已结算盘面 |
| removeTokens / remove | 删除、删除符号 | 删除券／移除 | 主动移出单张生产牌 | 不触发消费或销毁奖励 |
| choose / skip | 选符号、跳过 | 选择并入账／跳过并入账 | 处理候选并提交该轮收益 | 跳过不放弃已定收入 |
| consume | 吃掉、消费 | 消耗 | 结构效果移除目标并发对应成功事件 | 要区分来源奖励与目标损失 |
| destroy | 删掉、自毁 | 销毁／自毁 | 规则指定的销毁事件 | 不与主动移除混用 |
| transform | 升级、变身 | 转换 | 同实例换类型 | 不等于新建另一张牌 |
| permanent / growth | 永久升级 | 永久成长（本局内） | 单张实例通用永久值增加 | 不加到同名所有牌 |
| age / cycle_count | 轮数、成熟度 | 上盘次数／拍点计数 | 按实例出现推进 | 不按未上盘轮次推进 |
| pressure counter | 压力 | 蓄压 | 明确拥有该机制的实例计数 | 标签本身不给计数机制 |
| rarity | 品质 | 稀有度 | 候选分类与权重层 | 高稀有不保证适合或通关 |

## 4. 内容说明模板与核实范例

保留现有诗意卡名，不全量重命名。
格式：**名称＋角色/功能短句＋完整效果**；短句帮助看用途，不能替代完整规则。
完整效果必须交代条件、范围、目标数、时点、奖励、代价、次数与例外。
玩家正文去掉步骤号等开发词，技术详情仍可查完整合同与因果账本。
以下以GDD §5、§6规格为准；现行 `playerText.js` 提供中文用途与完整效果，详情和图鉴复用同一正文。

- **分温夹｜把邻接废料变成现金。** 基础值1；每轮消耗一个邻接废料，获得独立奖励6。无目标时只有基础1，不另发奖励；被消耗目标不再有普通产出。
- **和音框｜异种共鸣的邻接放大器。** 基础值2；本轮检查相邻组合时，若邻接至少两种其他共鸣生产牌，则按稳定顺序使一张相邻共鸣牌的普通产出×2。目标随后被消耗或销毁不补选；不是给全排或所有共鸣×2。准确判定窗口仍按GDD §5.I，短句不更改时序。
- **先支邮戳｜预支收益，增加账单并留下垃圾。** 基础值2；运行前选择接受或拒绝，默认拒绝。接受后每期该实例首次上盘获独立奖励18，本期应付增加12并尝试生成待核欠条。奖励计入本轮待入账，选择或跳过后才入现金，不是开启设置时立即发钱。生成失败不撤销奖励与义务；移除、转换或关闭接受不撤销已加应付。
- **公用节拍器｜加快拍点，不加快所有成长。** 本局升级，不上盘；拍点线轴阈值降低1，最低2，同cycle_count机制也适用。不改年龄或蓄压阈值，不当场触发旧计数，下一次上盘推进时结算。

## 5. 模式与文案示范

内容模式（profile）：full-v1显示**完整模式**；slice-abd-v1显示**精简模式（试验）**。
难度（difficulty）：当前两种内容模式都使用Normal，玩家名为**标准难度**；Normal不等同full-v1。
精简模式仅培育／回收／蒸馏内容，同样10期70轮；基础账单为完整模式的65%向上取整，约低35%，事件或借支增额另计。
精简模式不是已验证容易通关的教程，不计正式平衡验收；对应合法内容、起手与资源仍按规则合同。
Hard／Nightmare仍是未开放提案，不改内部Normal字段或profile标识。

### 首屏

**雾港回收工坊**
你接手了一间负债的回收工坊。让材料、设备与帮手配合赚钱，在每期截止前付清账单。

### 简介与操作

简介：随机上盘，组合赚钱；每轮选择一张生产牌或跳过，逐步救活工坊。
运行提示：从生产牌库抽取至多20张，随机放入5×4盘面，无需也不能手动摆牌。
顶栏：现金／待入账／本期应付／本期剩余运行。
候选提示：本轮收益已确定；新牌从未来运行起才可能上盘。
末轮提示：选择或跳过后入账并付款；新增牌不能补本期缺口。
刷新提示：消耗1刷新券，换整组候选，不改变本轮盘面或待入账。
移除提示：消耗1删除券，移出这张生产牌；不会撤销本轮已定收益，也不触发销毁奖励。
升级提示：选择一项本局升级；不上盘，只在本局生效，可放弃奖励。

### 胜败

完整胜利：**工坊保住了！你已付清10期账单。**
精简胜利：**精简模式完成：已付清10期试验账单。** 附注：“试验模式通关，不代表完整模式通关。”
失败：**本局经营失败：本期账单未付清。** 展示本期应付、可付现金与缺口。
失败诊断展示最近五轮均值、牌库大小、关键牌出现记录；不指责一次选择或保证重试必胜。
